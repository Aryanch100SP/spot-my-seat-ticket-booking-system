# 🎬 Spot My Seat – Ticket Booking System

## 🚀 Overview

Spot My Seat is a full-stack movie ticket booking system designed to provide a fair and efficient booking experience. It solves common problems like high convenience fees, mass bookings, and lack of priority for genuine users.

---

## ✨ Features

* 🎟️ Real-time seat availability
* ⚡ Priority booking system
* 🚫 Prevention of mass bookings
* 💳 QR-based payment system (auto-filled amount)
* 📊 Dynamic pricing based on date
* 🔔 Booking confirmation system

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask (Python)
* **Database:** MySQL
* **Other:** QR Code Integration, WebRTC concepts

---

## 🧠 How It Works

* Users login and select movies
* System shows real-time seat availability
* Booking is processed via Flask backend
* Payment is done through QR system
* Booking confirmation is generated instantly
